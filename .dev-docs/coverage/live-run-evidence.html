2. Integration evidence (your .dev-docs/integrations index)

A new command, yarn mercato agency_research journal --order-ref <ref>, turns an order's persisted rows into journal events: every task run becomes a checkpoint, every referenced agent_runs row an agent observation with its agentRunId, and a handoff is recorded only from saved lineage (the producer step's last ok run → the consumer step's first, or the brief-review userTaskId). No prompts, outputs or customer text leave the database. The three JSONL files sit in the gitignored journals/; the regenerated generated/index.json and report are committed.
