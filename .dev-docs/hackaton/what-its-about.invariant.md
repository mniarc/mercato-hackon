What it's about
Most "AI demos" stop at a chatbot. In this track we go further: the agent doesn't chat, it works. It picks up a request, looks for information, analyzes data, makes a decision, and triggers the next step of the process - and a human steps in only where they're truly needed.

The Agent Orchestrator in Open Mercato gives you the building blocks:

Agents and their skills - define who the agent is, what it can do, and what it's responsible for.
Subagents - break a complex task down into smaller, specialized roles.
Web search - let the agent reach for up-to-date information from outside the system.
AI tools - create your own tools for the agent to use while it works.
Data access - the agent works on real data from Open Mercato modules (CRM, Catalog, Sales, and more).
Workflows - connect your agents' work into a planned, repeatable process.
The key word is safe. The Orchestrator's architecture is built on the principle "The Agent Proposes. The System Decides." - the agent returns a proposal, and deterministic system logic decides what actually happens. That lets you give agents real work to do without handing them control of the company.

How to approach it:

Pick a process - something people in a company do today that's repetitive and time-consuming (e.g. lead qualification, complaint handling, preparing quotes, customer onboarding).
Break it down into steps - where the process starts, what decisions need to be made, how it ends.
Assign roles to agents - who gathers information, who analyzes, who proposes a decision, who takes action.
Define the boundaries - what an agent can propose, what the system approves automatically, and where a human is needed.
Wire it into a workflow - and run the process from trigger to final outcome.
