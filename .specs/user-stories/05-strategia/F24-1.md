# F24-1 · Akceptacja pary strategia i tone of voice

Źródło merytoryczne: AI_Company_Open_Mercato_Proces_v2.xlsx. Sposób opisu: riscore V2. Status oznacza ustalenie zakresu, a nie wdrożenie.

### Nazwa funkcjonalności

Akceptacja pary strategia i tone of voice

### Definicja

Klient otrzymuje wskazane wersje dwóch osobnych dokumentów wraz z uzasadnieniem i może je zatwierdzić lub skomentować. System zapisuje decyzje uprawnionego klienta po obsłudze przez G; dopiero komplet aktualnych akceptacji otwiera planowanie.

### Krok procesu

5.5

### ID historii

F24-1

### User story

Jako klient chcę zobaczyć aktualną strategię i tone of voice z krótkim uzasadnieniem, żeby zaakceptować oba dokumenty albo wskazać, co wymaga zmiany.

### Kryteria akceptacji

1. Klient otrzymuje oba dokumenty po pozytywnym QA, z widocznymi identyfikatorami wersji i uzasadnieniem kluczowych wyborów.
2. Może zaakceptować oba, zgłosić uwagi do jednego lub obu, zapytać, wstrzymać pracę albo zmienić kierunek.
3. Każda odpowiedź jest przekazywana do G.1; lokalny agent nie klasyfikuje ponownie zakresu ani wpływu.
4. System zapisuje przekazaną parę i stan oczekiwania na decyzję, nie traktując samego wysłania jako akceptacji.
5. Kontrakt decyzji jest niezależny od wyboru maila albo panelu; ten wybór pozostaje otwarty.

### Podstawa ustalenia

Jedna odpowiedź wskazuje oba dokumenty i trafia do G. Zasady produktu: Interfejs klienta; Decyzje: DEC-KIERUNEK. Źródło: arkusz Proces, kroki 5.5.
