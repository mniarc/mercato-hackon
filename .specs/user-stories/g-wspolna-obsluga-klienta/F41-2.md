### User story

Jako klient chcę akceptować dokładnie tę wersję materiału, którą obejrzałem, żeby moja zgoda nie zatwierdzała innych lub późniejszych treści.

### Kryteria akceptacji

1. Przed wykonaniem dyspozycji akceptacji system sprawdza aktualną wersję i uprawnienie kontaktu.
2. Zapis decyzji wskazuje osobę, czas, źródło decyzji, ID dokumentu i jego wersję.
3. Odpowiedź dotycząca starej wersji nie nadaje akceptacji wersji aktualnej ani przyszłej.
4. Zgoda ze zmianą jest obsługiwana jako uwaga; nie otwiera bramki kolejnego etapu.
5. Nowa wersja treści wymaga właściwej nowej akceptacji, a wcześniejsza zgoda pozostaje w historii.

### Podstawa ustalenia

Proces, G.5: aktualna wersja i uprawniony kontakt; G.2: akceptacja z prośbą o zmianę. Decyzje, DEC-AKCEPTACJA: osoba/czas/ID/wersja/źródło oraz zgoda ze zmianą jako uwaga. Zasady produktu: Dokumenty.
